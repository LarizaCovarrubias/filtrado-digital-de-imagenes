# Ejercicio 06 — Ruido y filtros de suavizado

**Propósito:** aplicación y análisis.

Usa un recorte de la fotografía principal en escala de grises.

1. Genera una versión con ruido Gaussiano y otra con ruido sal-pimienta.
2. Aplica filtros promedio, Gaussiano y mediana con kernel `5 × 5`.
3. Visualiza los resultados para cada tipo de ruido.
4. Repite uno de los filtros con kernel `3 × 3` y `7 × 7` para observar el efecto del tamaño.
5. Decide qué filtro conserva mejor los bordes para cada tipo de ruido y justifica tu respuesta.
