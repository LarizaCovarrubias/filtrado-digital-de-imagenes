# Ejercicio 05 — CLAHE

**Propósito:** aplicación y análisis.

Usa la fotografía principal y genera una versión con iluminación no uniforme.

1. Aplica CLAHE con al menos dos valores de `clipLimit`.
2. Repite con al menos dos valores de `tileGridSize`.
3. Visualiza las configuraciones lado a lado.
4. Elige la configuración que, según tu observación, conserve mejor los detalles sin amplificar demasiado las variaciones locales.
5. Justifica tu elección mencionando el efecto de ambos parámetros.
